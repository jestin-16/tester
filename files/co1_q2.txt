CO1 - Q2: EMPLOYEE PERFORMANCE REPORT & STATISTICAL ANALYSIS
================================================================================

PROBLEM STATEMENT:
Load an Employee Performance Dataset containing the following attributes for 30 employees:
  - Employee ID
  - Employee Name
  - Department (IT, HR, Sales, Marketing, Finance)
  - Experience (Years)
  - Performance Scores in 5 evaluation criteria:
      1. Quality of Work
      2. Productivity
      3. Teamwork
      4. Innovation
      5. Punctuality

Perform the following statistical analysis:
  - Mean
  - Median
  - Mode
  - Maximum
  - Minimum
  - Sum
  - Average
  - Standard Deviation
  - Variance

Based on the results, prepare a department-wise performance evaluation report
and identify the best-performing department.

--------------------------------------------------------------------------------
DATASET: 30 EMPLOYEES ACROSS 5 DEPARTMENTS & 5 CRITERIA
--------------------------------------------------------------------------------
Fields: EmpID, Name, Department, Experience, Quality, Productivity, Teamwork, Innovation, Punctuality
Scores range: 50 to 99 across all 5 evaluation criteria.

--------------------------------------------------------------------------------
PYTHON SOLUTION (DATASET CREATION & COMPLETE ANSWERS)
--------------------------------------------------------------------------------
import numpy as np
import pandas as pd

# Step 1: Create 30 Employee Records with 5 Departments and 5 Evaluation Criteria
np.random.seed(42)
departments = ["IT", "HR", "Sales", "Marketing", "Finance"]
criteria = ["Quality", "Productivity", "Teamwork", "Innovation", "Punctuality"]

names = [
    "Alice", "Bob", "Charlie", "David", "Emma", "Frank", "Grace", "Henry",
    "Ivy", "Jack", "Kavita", "Liam", "Mia", "Noah", "Olivia", "Peter",
    "Quinn", "Rose", "Sam", "Tina", "Uma", "Victor", "Wendy", "Xander",
    "Yara", "Zack", "Kiran", "Meera", "Deepak", "Ananya"
]

data = {
    "EmpID": [f"EMP{i:03d}" for i in range(1, 31)],
    "Name": names,
    "Department": np.random.choice(departments, size=30),
    "Experience": np.random.randint(1, 15, size=30)
}

for crit in criteria:
    data[crit] = np.random.randint(50, 100, size=30)

df = pd.DataFrame(data)

# Step 2: Criteria-wise Statistical Summary (Mean, Median, Mode, Max, Min, Sum, Std, Var)
criteria_stats = pd.DataFrame({
    "Mean": df[criteria].mean().round(2),
    "Median": df[criteria].median().round(2),
    "Mode": df[criteria].mode().iloc[0],
    "Maximum": df[criteria].max(),
    "Minimum": df[criteria].min(),
    "Sum": df[criteria].sum(),
    "Std_Dev": df[criteria].std().round(2),
    "Variance": df[criteria].var().round(2)
})

# Step 3: Employee-level Total and Average Performance Score
df["Total_Score"] = df[criteria].sum(axis=1)
df["Avg_Performance"] = (df["Total_Score"] / len(criteria)).round(2)

# Step 4: Department-wise Performance Evaluation Report
dept_report = df.groupby("Department").agg(
    Employee_Count=("EmpID", "count"),
    Avg_Experience=("Experience", "mean"),
    Avg_Performance=("Avg_Performance", "mean"),
    Min_Performance=("Avg_Performance", "min"),
    Max_Performance=("Avg_Performance", "max"),
    Performance_Std=("Avg_Performance", "std")
).round(2).reset_index()

# Step 5: Identify the Best Performing Department
best_dept = dept_report.sort_values(by="Avg_Performance", ascending=False).iloc[0]

# Display Results
print("=== 1. EMPLOYEE DATASET (FIRST 5 RECORDS) ===")
print(df[["EmpID", "Name", "Department", "Experience"] + criteria].head().to_string(index=False))

print("\n=== 2. CRITERIA-WISE STATISTICAL SUMMARY ===")
print(criteria_stats.to_string())

print("\n=== 3. DEPARTMENT-WISE PERFORMANCE REPORT ===")
print(dept_report.to_string(index=False))

print("\n=== 4. BEST PERFORMING DEPARTMENT ===")
print(f"Department Name:        {best_dept['Department']}")
print(f"Average Score:          {best_dept['Avg_Performance']} / 100")
print(f"Total Employees:        {best_dept['Employee_Count']}")
print(f"Avg Years Experience:   {best_dept['Avg_Experience']} years")
