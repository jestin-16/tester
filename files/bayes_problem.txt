PROBLEM STATEMENT:
Consider a set of patients coming for treatment in a certain clinic.
Let A denote the event that a "Patient has liver disease".
Let B denote the event that a "Patient is an alcoholic".

GIVEN CLINICAL VALUES:
  - P(A)   = 0.10  (10% of patients entering the clinic have liver disease)
  - P(B)   = 0.05  (5% of patients entering the clinic are alcoholics)
  - P(B|A) = 0.07  (Among patients diagnosed with liver disease, 7% are alcoholics)

QUESTION:
Given that a patient is an alcoholic, what is the probability that he will
have liver disease? Find P(A|B).

--------------------------------------------------------------------------------
1. MATHEMATICAL DERIVATION (STEP-BY-STEP)
--------------------------------------------------------------------------------
Bayes' Theorem Formula:
           P(B|A) * P(A)
P(A|B) = -----------------
               P(B)

Substitute the given values into the formula:
           0.07 * 0.10
P(A|B) = ---------------
               0.05

           0.007
P(A|B) = ---------
            0.05

P(A|B) = 0.14 = 14.0%

Conclusion:
The probability that an alcoholic patient entering the clinic has liver disease
is 0.14 (14%).

--------------------------------------------------------------------------------
2. PYTHON SOLUTION
--------------------------------------------------------------------------------
def calculate_bayes(p_a, p_b, p_b_given_a):
    """
    Computes posterior probability P(A|B) using Bayes' Theorem.
    """
    return (p_b_given_a * p_a) / p_b

# Given Prior & Likelihood Values
P_LiverDisease = 0.10            # P(A)
P_Alcoholic = 0.05               # P(B)
P_Alcoholic_Given_Liver = 0.07   # P(B|A)

# Calculate Posterior Probability P(A|B)
P_Liver_Given_Alcoholic = calculate_bayes(P_LiverDisease, P_Alcoholic, P_Alcoholic_Given_Liver)

print("=== BAYES THEOREM CALCULATION RESULTS ===")
print(f"P(Liver Disease)                  = {P_LiverDisease:.2f}")
print(f"P(Alcoholic)                      = {P_Alcoholic:.2f}")
print(f"P(Alcoholic | Liver Disease)      = {P_Alcoholic_Given_Liver:.2f}")
print("------------------------------------------")
print(f"P(Liver Disease | Alcoholic)      = {P_Liver_Given_Alcoholic:.4f} ({P_Liver_Given_Alcoholic * 100:.1f}%)")
