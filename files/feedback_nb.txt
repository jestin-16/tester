  4. Split the dataset into training and testing sets using an 80:20 ratio.
  5. Train a Multinomial Naive Bayes model without Laplace smoothing (alpha ~ 0).
  6. Train another model using Laplace smoothing with alpha = 1.

 11. Display the predicted class probabilities.

PYTHON SOLUTION (EMBEDDED 25-ROW CSV & COMPLETE NAIVE BAYES PIPELINE)

import io
import pandas as pd
import numpy as np
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import MultinomialNB

# Step 1: 25-Row Student Feedback Dataset (Embedded CSV)
csv_data = """MessageID,Message,Class
M01,The professor explains concepts with remarkable clarity and patience,Positive
M02,Terrible experience lab computers are slow and constantly crashing,Negative
M03,Excellent practical demonstrations and insightful project guidance,Positive
M04,Extremely boring lectures with completely outdated syllabus slides,Negative
M05,Great interactive doubt clearing sessions and friendly staff support,Positive
M06,Rude behavior from lab assistant and useless lab manuals,Negative
M07,Well organized course curriculum with great real world relevance,Positive
M08,Very confusing explanations and impossible exam evaluation criteria,Negative
M09,Thoroughly enjoyed the hands on programming exercises and feedback,Positive
M10,Disorganized schedule and frequent last minute class cancellations,Negative
M11,Inspiring teacher with immense knowledge and supportive guidance,Positive
M12,Dull monotonous voice and zero practical implementation taught,Negative
M13,Outstanding learning environment and highly encouraging faculty,Positive
M14,Poor guidance for final semester project work and delayed marks,Negative
M15,The assignments were challenging interesting and highly educational,Positive
M16,Worst course structure and terribly disorganized lab instructions,Negative
M17,Fantastic coverage of algorithms and real world applications,Positive
M18,Frustrating grading system with biased evaluation marks,Negative
M19,Engaging presentation skills and clear step by step tutorials,Positive
M20,Complete waste of time reading directly from textbook without examples,Negative
M21,Comprehensive lecture notes and prompt doubt resolution online,Positive
M22,Unfair penalties on late submissions without any prior notice,Negative
M23,Helpful code walkthroughs and regular interactive quizzes,Positive
M24,Strict attendance policy with zero flexibility for medical issues,Negative
M25,Highly motivating lectures with industry case study examples,Positive
"""

df = pd.read_csv(io.StringIO(csv_data))
with open("feedback.csv", "w") as f:
    f.write(csv_data.strip())

# Step 2: Inspect first 5 records & class distribution
print("=== 1. DATASET OVERVIEW & CLASS DISTRIBUTION ===")
print("First 5 records:\n", df.head())
print("\nClass Distribution:\n", df["Class"].value_counts())

# Step 3: Vectorize text using CountVectorizer (Bag of Words)
vectorizer = CountVectorizer(stop_words="english")
X = vectorizer.fit_transform(df["Message"])
y = df["Class"]
vocab = vectorizer.get_feature_names_out()

# Step 4: Split into 80% Train (20 messages), 20% Test (5 messages)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, random_state=42, stratify=y
)

# Step 5: Train Model WITHOUT Laplace Smoothing (alpha = 1e-9)
model_no_lap = MultinomialNB(alpha=1e-9)
model_no_lap.fit(X_train, y_train)

# Step 6: Train Model WITH Laplace Smoothing (alpha = 1.0)
model_with_lap = MultinomialNB(alpha=1.0)
model_with_lap.fit(X_train, y_train)

# Step 7 & 8: Unseen Word Probability Demonstration
# Formula: P(w | C) = (Count(w, C) + 1) / (N_C + V)
V = len(vocab)
classes = model_with_lap.classes_
print("\n=== 2. UNSEEN WORD PROBABILITY FORMULA ===")
print(f"Total Unique Vocabulary Size (V): {V} words")

unseen_word = "quantum"
print(f"For an unseen test word like '{unseen_word}':")
for i, c in enumerate(classes):
    N_c = model_with_lap.feature_count_[i].sum()
    p_unseen = 1.0 / (N_c + V)
    print(f"   In Class '{c}': Count=0, Total Words N_C={int(N_c)}, P('{unseen_word}'|{c}) = (0+1)/({int(N_c)}+{V}) = {p_unseen:.6f}")

# Step 9: Compare Predictions on Test Split
preds_no = model_no_lap.predict(X_test)
preds_lap = model_with_lap.predict(X_test)

comparison_df = pd.DataFrame({
    "Test_Message": [df["Message"].iloc[idx] for idx in y_test.index],
    "Actual_Class": y_test.values,
    "No_Laplace_Prediction": preds_no,
    "With_Laplace_Prediction": preds_lap
})
print("\n=== 3. TEST SET PREDICTIONS COMPARISON ===")
print(comparison_df.to_string(index=False))

# Step 10 & 11: Accept New Feedback & Predict with Probabilities
new_sample = "The teacher explained difficult topics with outstanding clarity"
new_vec = vectorizer.transform([new_sample])

pred_class = model_with_lap.predict(new_vec)[0]
probs = dict(zip(model_with_lap.classes_, model_with_lap.predict_proba(new_vec)[0].round(4)))

print(f"\n=== 4. PREDICTION ON NEW USER FEEDBACK ===")
print(f"Input Message:  '{new_sample}'")
print(f"Predicted Class: {pred_class}")
print(f"Class Probabilities: {probs}")

# Step 12: Explanation of Zero-Probability Problem
print("\n=== 5. HOW LAPLACE ESTIMATION PREVENTS ZERO PROBABILITIES ===")
print("In Naive Bayes, the class score is computed as the product of conditional probabilities:")
print("   P(Class) * P(w1|Class) * P(w2|Class) * ... * P(wn|Class)")
print("If a single word does not appear in a training class, its count is 0, making P(wi|Class) = 0.")
print("This single zero causes the entire multiplicative product to collapse to zero, regardless of other words.")
print("Laplace smoothing adds alpha=1 to the numerator and V to the denominator, guaranteeing every word")
print("has a non-zero probability and ensuring robust classification on real-world text.")
