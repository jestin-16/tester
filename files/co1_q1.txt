PROBLEM STATEMENT:
Load a student dataset containing the details of 25 students with the following fields:
  - Student ID
  - Student Name
  - Marks obtained in 5 subjects (Maths, Physics, Chemistry, English, CS)

Perform the following statistical analyses on the dataset:
  1. Calculate the Mean of marks for each subject.
  2. Calculate the Median of marks for each subject.
  3. Calculate the Mode of marks for each subject.
  4. Find the Maximum mark obtained in each subject.
  5. Find the Minimum mark obtained in each subject.
  6. Calculate the Sum of marks for each subject.
  7. Calculate the Average marks for each student.
  8. Calculate the Total marks for each student.
  9. Determine the overall Class Average.
 10. Prepare a Class Performance Evaluation based on the statistical results.

--------------------------------------------------------------------------------
DATASET: 25 STUDENTS WITH 5 SUBJECTS
--------------------------------------------------------------------------------
Fields: StudentID, Name, Maths, Physics, Chemistry, English, CS
Marks range: 45 to 99 across all 5 subjects.

--------------------------------------------------------------------------------
PYTHON SOLUTION (DATASET CREATION & COMPLETE ANSWERS)
--------------------------------------------------------------------------------
import numpy as np
import pandas as pd

# Step 1: Create Dataset with 25 Students and 5 Subjects
np.random.seed(42)
subjects = ["Maths", "Physics", "Chemistry", "English", "CS"]

data = {
    "StudentID": [f"STU{i:03d}" for i in range(1, 26)],
    "Name": [
        "Aarav", "Aditi", "Bhavya", "Chetan", "Divya", "Esha", "Farhan",
        "Gaurav", "Harini", "Ishaan", "Jaya", "Karan", "Lavanya", "Manish",
        "Neha", "Omkar", "Pooja", "Rahul", "Sneha", "Tarun", "Usha",
        "Varun", "Vidya", "Yash", "Zoya"
    ]
}

# Generate marks between 45 and 99
for sub in subjects:
    data[sub] = np.random.randint(45, 99, size=25)

df = pd.DataFrame(data)

# Step 2: Subject-wise Statistical Analysis (Mean, Median, Mode, Max, Min, Sum)
sub_stats = pd.DataFrame({
    "Mean": df[subjects].mean().round(2),
    "Median": df[subjects].median().round(2),
    "Mode": df[subjects].mode().iloc[0],
    "Maximum": df[subjects].max(),
    "Minimum": df[subjects].min(),
    "Sum": df[subjects].sum()
})

# Step 3: Student-wise Total and Average marks
df["Total_Marks"] = df[subjects].sum(axis=1)
df["Average_Marks"] = (df["Total_Marks"] / len(subjects)).round(2)

# Step 4: Overall Class Average
class_avg = df["Average_Marks"].mean().round(2)

# Step 5: Class Performance Evaluation
def evaluate_performance(avg):
    if avg >= 85:
        return "Distinction"
    elif avg >= 70:
        return "First Class"
    elif avg >= 50:
        return "Second Class"
    else:
        return "Needs Improvement"

df["Performance"] = df["Average_Marks"].apply(evaluate_performance)

# Display Results
print("=== 1. STUDENT DATASET (FIRST 5 RECORDS) ===")
print(df[["StudentID", "Name"] + subjects].head().to_string(index=False))

print("\n=== 2. SUBJECT-WISE STATISTICAL ANALYSIS ===")
print(sub_stats.to_string())

print(f"\n=== 3. OVERALL CLASS AVERAGE: {class_avg} ===")

print("\n=== 4. CLASS PERFORMANCE EVALUATION SUMMARY ===")
print(df["Performance"].value_counts().to_string())

print("\n=== 5. TOP 3 PERFORMERS ===")
top_3 = df.sort_values(by="Total_Marks", ascending=False).head(3)
print(top_3[["StudentID", "Name", "Total_Marks", "Average_Marks", "Performance"]].to_string(index=False))
